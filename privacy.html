Privacy Policy / 개인정보처리방침

Last updated / 최종 수정: 2026-10-14

1. Who uses this app / 사용 주체

Liv is a personal app used only by its owner with the owner's own Google accounts. It is not distributed to or used by other people.
Liv은 소유자 본인이 본인의 구글 계정으로만 쓰는 개인용 앱이며, 다른 사람에게 배포되거나 사용되지 않습니다.

2. Google user data we access / 접근하는 구글 데이터

With the owner's consent the app requests these Gmail scopes: gmail.send (send email) and gmail.readonly (read email).
소유자의 동의 아래 Gmail 메일 발송(gmail.send)과 열람(gmail.readonly) 권한만 요청합니다.

3. How data is used / 이용 방식

Data is used only to perform tasks the owner requests, such as sending a message or reading a message. It is not used for advertising or sold.
소유자가 요청한 작업(메일 발송, 메일 읽기)을 수행하는 용도로만 쓰며, 광고에 쓰거나 판매하지 않습니다.

4. Sharing and storage / 공유와 저장

We do not share Google user data with third parties. Access tokens are stored only on the owner's own computer. We do not operate a server that collects data from other users.
구글 사용자 데이터를 제3자와 공유하지 않습니다. 접근 토큰은 소유자 본인 컴퓨터에만 저장되며, 다른 사용자의 데이터를 수집하는 서버는 운영하지 않습니다.

5. Compliance / 정책 준수

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and contact / 권한 철회와 문의
